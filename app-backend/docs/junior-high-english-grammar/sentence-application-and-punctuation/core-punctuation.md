# 核心標點符號的運用

## 概念說明

標點符號是書面語中不可或缺的輔助符號，它們就像語言中的停頓、重音和語氣，幫助我們清晰地表達意思，並區分句子的層次關係。核心標點符號包括句號（。）、逗號（，）、問號（？）、驚嘆號（！）、引號（「」或“ ”）等。

句號用於標示一個完整的句子結束；逗號則用於分隔句子中的分項、描述或停頓；問號用於標示疑問句的結尾；驚嘆號則用於表達強烈的感受或感嘆。引號則用於標示引述的內容或特殊詞語。正確運用這些標點符號，能讓文字的意義更加明確、邏輯更流暢，避免產生歧義。掌握這些基礎標點符號的運用，是提升寫作表達能力的重要一步。

## 範例

**範例一：逗號的運用（分隔分項和描述）**

請觀察以下句子，並注意逗號的作用：

*   小明喜歡吃蘋果、香蕉和橘子。
*   今天天氣很熱，可是我們還是決定去公園玩。

**範例二：引號的運用（引述對話）**

引號用於標示直接的對話內容：

*   媽媽問我：「你今天做了什麼？」
*   他對朋友說：「我已經準備好了。」

**範例三：句號與問號的區分**

請區分陳述句和疑問句的標記：

*   我喜歡讀書。 (陳述句，用句號結尾)
*   你喜歡讀書嗎？ (疑問句，用問號結尾)

## 練習題

**練習一：標記句子類型**

請判斷下列句子應使用句號（。）、逗號（，）、問號（？）、驚嘆號（！），並在空格中填入適當的標點符號。

1. 你的書包裡有筆和鉛筆嗎
2. 今天的天氣真好漂亮
3. 我喜歡吃冰淇淋香甜又冰涼

**練習二：正確使用引號**

請將下列對話句子中的引號標記正確：

「你今天有什麼打算？」小華問道。

**練習三：句子重組**

請將下列句子使用適當的標點符號重新組織，使其語意更清晰：

我今天去商店買了牛奶 麵包 和雞蛋。

### 參考答案

**練習一：標記句子類型**

1. 你的書包裡有筆和鉛筆嗎？
2. 今天的天氣真好漂亮！
3. 我喜歡吃冰淇淋，香甜又冰涼。

**練習二：正確使用引號**

「你今天有什麼打算？」小華問道。

**練習三：句子重組**

我今天去商店買了牛奶、麵包和雞蛋。
