# 句子類型與語氣

## 概念說明

句子是語言的基本單位，它必須包含主語、謂語等要素，才能表達完整的意思。我們根據句子的「功能」來區分不同的句子類型，以及根據說話者的「情感」來區分不同的語氣。

**句子類型**主要根據句子表達的目的來分類，例如陳述句（告知事實）、疑問句（提出問題）、祈使句（發出命令或請求）、感嘆句（表達強烈的情感）。

**語氣**則是指說話者在表達內容時所帶有的情感和態度。例如，語氣可以是平靜、生氣、興奮、嚴肅或溫和。語氣會影響我們對句子的理解，即使詞語相同，不同的語氣也會產生不同的感覺。理解句子類型和語氣，有助於我們更精準地理解和表達語言的細微差別。

## 範例

### 1. 陳述句 (Declarative Sentence)
**類型：** 用來陳述事實或觀點。
**語氣：** 通常是平靜、客觀。
**範例：** 今天的天氣很熱。

### 2. 疑問句 (Interrogative Sentence)
**類型：** 用來提出問題。
**語氣：** 可能表達好奇、詢問、擔憂等。
**範例：** 你喜歡吃甜食嗎？

### 3. 祈使句 (Imperative Sentence)
**類型：** 用來發出命令、請求或建議。
**語氣：** 可能表達堅定、懇求或友善。
**範例：** 請把你的作業交給我。

### 4. 感嘆句 (Exclamatory Sentence)
**類型：** 用來表達強烈的喜悅、驚訝、憤怒或感嘆。
**語氣：** 充滿情緒。
**範例：** 哇！這場演出太精彩了！

## 練習題

**請判斷下列句子屬於哪一種類型，並試著描述其語氣。**

**題目 1：** 請大家保持安靜。
**答案：** 祈使句。語氣通常是要求或命令。

**題目 2：** 你覺得這本書有趣嗎？
**答案：** 疑問句。語氣通常是好奇或詢問。

**題目 3：** 天空是藍色的，陽光照在我們身上。
**答案：** 陳述句。語氣通常是平靜、客觀。
