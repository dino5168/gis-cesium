Type Guard
export function isParentNavItem(
  item: NavItem
): item is ParentNavItem {
  return Array.isArray(item.children);
}

// 使用點（AppSidebar.tsx）
const isParent = isParentNavItem(item);
if (isParent && !collapsed)
  toggleExpand(item.key)

利用 children?: never 與 children: LeafNavItem[] 構成判別聯合（discriminated union），type narrowing 零運行時成本。

5 主題切換機制
useLayoutEffect — DOM class 操作
useLayoutEffect(() => {
  const root = document.documentElement;
  root.classList.remove("dark", "dark-blue");

  if (theme === "dark")
    root.classList.add("dark");
  else if (theme === "dark-blue")
    root.classList.add("dark-blue");
  else if (theme === "system") {
    const prefersDark = window
      .matchMedia("(prefers-color-scheme: dark)")
      .matches;
    if (prefersDark) root.classList.add("dark");
  }
}, [theme]);
四種 Theme 選項
ValueIcon行為
systemMonitor讀取 OS 偏好，自動套用 .dark
lightSun移除所有 dark class
darkMoon加上 .dark
dark-blueWaves加上 .dark-blue
為什麼用 useLayoutEffect？
在瀏覽器繪製前同步更新 class，避免 light → dark 的閃爍（FOUC）。
6 設定面板 Click-outside 關閉
useEffect + mousedown 事件委派
useEffect(() => {
  if (!settingsOpen) return; // early exit — 未開啟時不掛事件

  const handler = (e: MouseEvent) => {
    if (settingsRef.current &&
        !settingsRef.current.contains(e.target as Node)) {
      setSettingsOpen(false);
      setThemeExpanded(false);
      setLangExpanded(false);
    }
  };

  document.addEventListener("mousedown", handler);
  return () => document.removeEventListener("mousedown", handler);
}, [settingsOpen]);
關鍵細節
  • settingsRef 包裹整個 Footer div（含 popup + footer bar），contains() 判斷點擊是否在內部
  • 只在 settingsOpen === true 時才掛 listener，避免每次 render 多餘的全域事件
  • cleanup 函數確保 unmount 或狀態變更時移除 listener，防止記憶體洩漏
closePopup 輔助函式
const closePopup = () => {
  setSettingsOpen(false);
  setThemeExpanded(false);
  setLangExpanded(false);
};

選擇主題 / 語言後呼叫，同步重置三個狀態，避免下次開啟時殘留展開狀態。

子選單展開（toggleExpand）
const toggleExpand = (key: NavItemKey) => {
  setExpandedItems((prev) => {
    const next = new Set(prev);
    next.has(key)
      ? next.delete(key)
      : next.add(key);
    return next;
  });
};

Set 支援同時展開多個 Parent 項目。 收合側邊欄時子選單不會重置（Set 保留），展開後子選單位置自動顯示。

Guard： 只有 isParent && !collapsed 才觸發 toggleExpand； collapsed 狀態點擊 Parent 只切換 activeItem，不試圖展開。
